# Documentación

- `axes/`: especificaciones funcionales del visor final, una por eje.
- `reference/`: material de auditoría, fuentes y modelo analítico/Supabase.
- `delivery/`: entregables transversales, incluida la futura guía de estilos.

Los PDF de `axes/` fijan preguntas, métricas, filtros, interacción, outliers, criterios de confianza y contratos de datos. La guía de estilos definirá después su expresión visual común.

Para iniciar desarrollo, cada eje puede tener además un contrato versionable en Markdown. El primero está en [Contrato de Flujos y recogidas](axes/01_Contrato_Flujos_y_Recogidas.md).
