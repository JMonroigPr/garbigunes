# Visor Garbigunes - piloto

Nueva aplicación del entregable final. Se construirá por módulos independientes que se integran en un visor común:

1. Flujos y recogidas.
2. Especialización de residuos.
3. Captación territorial.
4. Recursos y cobertura.
5. Circularidad, reservada.

Antes de implementar interfaz, usar como contrato funcional los PDF de `docs/axes/` y como contrato de datos `docs/reference/modelo_datos_supabase.md`.
