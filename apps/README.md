# Aplicaciones

## `legacy-dashboard`

Prototipo estático anterior. Mantiene la configuración de Vercel y los datos agregados que aún utiliza el pipeline de compatibilidad. No se debe usar como base directa del entregable final: sirve como referencia funcional y visual.

## `garbigunes-piloto`

Raíz reservada para el nuevo visor modular. Su arquitectura debe reflejar los ejes del piloto y consumir contratos de datos estables, preferentemente agregados y vistas de Supabase. La guía global de estilos se incorporará aquí cuando esté disponible.
